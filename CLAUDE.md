# DYNAMIC monorepo

Field-study platform: `expo/` (React Native field app, Android first),
`apps/api/` (Express + Drizzle API), `packages/` (shared domain/workflow),
`deploy/` (nginx + systemd). See `DEVELOPMENT.md` and `docs/android-ci.md`.

## Expo app
- Tests are plain scripts: `npx tsx expo/src/tests/validateX.mjs`, all chained in
  `expo/package.json` `"test"`. Every new test must be appended there.
- `npm --workspace expo test` and `npm --workspace expo run lint` must pass
  before committing. Lint errors block; warnings do not.
- Form definitions live in `expo/src/data/forms/*.json`. The API serves these
  same files (plus DB translations), so editing them is the only place to
  change a form. Bundled JSON is English-only.
- Form codes stay `HHQ`/`WQ` internally; the UI shows `BHQ`/`BWQ` via
  `src/lib/formDisplayCodes.js`.
- Anything lists/filters need from a draft or response must be a real SQLite
  column, not only inside a JSON blob.
- Interviewer consistency checks live in `src/lib/womanSurveyBehaviors.js`
  and `src/lib/householdSurveyBehaviors.js`; blocking rules go through
  `onValidateQuestion`, inline messages through `addQuestionMessage`.
- API URL comes from `EXPO_PUBLIC_API_BASE_URL` (`expo/.env` locally, the
  `API_BASE_URL` GitHub secret in CI). Never hard-code the real domain.

## Releases
- `git tag vX.Y.Z[-rc.N] && git push origin <tag>` builds a signed APK
  (APK only, no AAB). Bump `expo/app.json`, `expo/package.json` and the
  workspace entry in `package-lock.json` together.

## Conventions
- One commit per fix, tests included. Don't commit `.env*`, `.serena/`,
  `.trace-mcp/`, or `expo/android/` (generated by prebuild).
